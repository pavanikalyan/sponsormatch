# SponsorMatch AI — V3 Partnership Studio

A static, browser-based university prototype exploring how community clubs and business sponsors can discover opportunities, compare compatibility and manage sponsorship proposals.

## Run locally

Open `index.html` in a modern browser. No build process, account, database or server is required.

## Prototype features

- Club and sponsor discovery and profiles
- Compatibility scores, proposals and campaign brief builder
- Responsive dashboard and navigation
- Sample organisations and browser-local state (`localStorage`)

## Important limitations

This is a demonstration prototype, **not a production service**. Sample organisations and data are fictional. There is no live account authentication, server-side permission enforcement, payment processing, or real sponsor verification. Advanced AI recommendations and third-party AI image generation are not connected. Do not enter personal or sensitive information.

## GitHub Pages

For a static demonstration, go to **Settings → Pages → Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, and save. The published URL normally follows `https://pavanikalyan.github.io/sponsormatch/` after GitHub completes deployment.
